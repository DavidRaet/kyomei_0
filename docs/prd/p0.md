# Kyomei MVP P0 Feature Inventory

This file extracts the P0 items from [Kyomei-MVP-PRD-v2.md](Kyomei-MVP-PRD-v2.md) and groups them by the PRD's own feature categories.

## Authentication And Account Management

| Feature | Description |
|---|---|
| Sign Up | Email + password registration via Auth0 |
| Login | Auth0-managed session with JWT |
| Logout | Clear Auth0 session + redirect to home |
| User Profile | Store email, name, created_at, updated_at |

## Vibe Check Onboarding Survey

| Feature | Description |
|---|---|
| 5-Question Form | Captures user taste profile |
| Multi-Select Genres | Action, Romance, Comedy, Psychological, Slice-of-Life, Thriller, Drama, Horror, Fantasy, Sci-Fi |
| Mood Preference | Single select: Uplifting, Intense/Dark, Relaxing, Thought-Provoking |
| Episode Length | Short (<13), Medium (13-26), Long (26+) |
| Story Complexity | Light/Fun, Moderate, Deep/Philosophical |
| Maturity Level | SFW, PG-13, Mature |
| Form Validation | At least 1 genre + mood required |
| Save to Database | Store preferences in user_preferences table |

## Anime Catalog

| Feature | Description |
|---|---|
| Anime Titles via JikanAPI | Backend connects to the JikanAPI to retrieve anime information |
| Core Metadata | Title, description, genres, episode count, rating, year, poster URL |
| Genre/Tag Tagging | Each anime tagged with 2-5 genres |

## Content-Based Recommendation Engine

| Feature | Description |
|---|---|
| Tag Matching Algorithm | Surface anime where genres overlap with user preferences |
| Rating Boost | Prioritize highly-rated anime (4.5+ stars) |
| Ranking by Relevance | Return top 10-20 recommendations sorted by match score |
| Exclude Watched | Do not recommend anime the user already rated |
| Cold Start | First-time users get top-rated anime in preferred genres |

## Rating System

| Feature | Description |
|---|---|
| 5-Star Rating | User rates anime (1-5 stars, or skip) |
| Rate from Anywhere | Rate on detail page, recommendation card, or watchlist |
| Update Rating | User can change rating anytime |
| Timestamp Rating | Store when user rated (rated_at field) |

## Watchlist And Status Tracking

| Feature | Description |
|---|---|
| Status Categories | Plan to Watch, Watching, Completed, Dropped |
| Add to Watchlist | User adds anime to any category from detail page |
| Update Status | Move anime between categories |
| View Watchlist | Dedicated page showing all categorized anime |

## Dashboard And Home Feed

| Feature | Description |

## Search And Browse

## P0 User Stories

These user stories are also marked P0 in the PRD and support the same core loop:

| Story | Outcome |
|---|---|
| Sign up with email | Create a personalized anime profile |
| Complete a 5-question vibe check | Help the system understand user taste |
| See recommendations based on vibe | Find anime that matches preferences |
| Rate anime 1-5 stars | Teach the system what the user likes |
| Add anime to watchlist | Track what to watch, watch, or complete |
| See why a recommendation appears | Build trust in the recommendation system |
| Receive improved recommendations after more ratings | Improve taste prediction over time |
